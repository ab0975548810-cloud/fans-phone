POS 通用獨立版 V1.2
====================

本版重點
1. 取消主管 / 員工雙層權限：每位使用者只需「名字 + 個人 PIN」登入。
2. 所有人登入後都可操作 POS、商品、庫存、進貨、歷史單據、費用、設定。
3. 新增「操作紀錄」頁：記錄登入、結帳、編輯單據、作廢、進貨、復原、商品設定、費用設定等操作的人員、時間、內容。
4. 日報表保留原本形式與手寫匯出。
5. 月報表重新設計：月營業額、總成本、總支出、月淨利、總銷量、營業天數、日均營業額、最高營業日、每日營業表現、每日走勢、商品排行、付款方式、費用分類、本月值班人員。
6. 手寫報表與右下角兩隻貓浮水印保留，圖片位置仍為 static/image.png。

資料與部署
- 單店使用單一 pos.db。
- Zeabur 有 /data 時會把資料庫與備份放在 /data。
- 第一次開啟會要求店名、第一位使用者名稱、個人 PIN。
- 其他人員可在「👥 人員」中新增，每個人設定自己的 PIN。

啟動
1. 安裝 requirements.txt
2. 確認資料夾：app.py / templates/index.html / static/image.png
3. 執行 python app.py

貓咪浮水印
本壓縮檔未內附原本兩隻貓圖片，請把原作品的圖片放到：
static/image.png
