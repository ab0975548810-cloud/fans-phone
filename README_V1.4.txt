POS 通用獨立版 V1.4
====================

本版在 V1.3「開班／關帳」基礎上加入三項已確認的優化：

1. 手機型號選擇 Bottom Sheet
   - 手機不再把型號清單塞在購物車卡片內，避免被鍵盤遮住。
   - 點「選擇型號」後由底部滑出獨立搜尋清單，顯示型號與目前庫存。
   - 平板／電腦保留原本快速下拉搜尋。
   - 手機 input / select / textarea 維持至少 16px，降低 iPhone Safari 自動放大。

2. 月報表改成「目標業績追蹤」
   - 可為每個月份各自設定目標業績。
   - 顯示目標、真實業績、還差／超標、達成率。
   - 顯示依日期推算的應有進度、目前超前／落後、剩餘天數與平均每日需完成業績。
   - 移除原本資料少時會變成大色塊的每日營業額走勢圖。
   - 每日營業表現、商品排行、付款方式、費用與值班人員仍保留。

3. 新增年報表
   - 年營業額、成本、支出、淨利、總銷量、訂單數。
   - 每年度可獨立設定年度業績目標。
   - 12 個月營運表現、平均月營業額／淨利、最佳／最低月份。
   - 與去年同期比較（當年度進行中時，以去年相同日期區間比較）。
   - 年度商品排行、付款方式、費用分類、值班人員。

升級方式
--------
- V1.3 的 pos.db 可以沿用，不必刪除資料。
- V1.4 啟動時會自動建立 report_targets 資料表。
- 若是新店，直接部署本資料夾即可。
- 兩隻貓手寫報表浮水印請自行放入：static/image.png

基本檔案
--------
app.py
requirements.txt
templates/index.html
static/image.png（需自行補原圖）

部署前建議先備份原本 pos.db。
