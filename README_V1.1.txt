POS 通用獨立版 V1.1
====================

這是以 V1 單店獨立母版延伸的操作體驗版。

【本次新增／修改】
1. 自適應 POS UI
   - 手機：商品兩欄大按鈕，底部顯示購物車摘要，點擊後由底部展開完整結帳區。
   - 平板：商品區＋購物車左右雙欄，方便櫃台觸控操作。
   - 電腦：商品區加寬，購物車固定於右側。
   - 商品數量少時自動放大卡片；商品很多時自動改為緊湊排列。

2. 歷史單據編輯
   - 在「改日期」旁新增「編輯」。
   - 可修改商品、型號、數量、單價、付款方式。
   - 修改時會自動退回原單庫存、檢查新單庫存、重新扣庫存並重算營業額／成本。
   - 顯示最後編輯人、編輯時間、編輯次數。
   - 已作廢單據不可再編輯。

3. 進貨紀錄稽核
   - 進貨單不提供永久刪除。
   - 作廢後仍保留原進貨單、建立人、建立時間。
   - 顯示作廢人／作廢時間。
   - 復原時顯示復原人／復原時間。
   - 編輯進貨單顯示最後編輯人／時間。
   - 作廢與復原會同步重新計算庫存。

4. 手寫報表費用支出
   - 保留原本手寫報表設計。
   - 保留右下角兩隻貓浮水印：/static/image.png
   - 在商品明細下方新增「費用支出」。
   - 分別顯示：租金、清潔費、電費、其他。
   - 金額為 0 的項目不顯示。

【兩隻貓浮水印】
程式仍固定讀取：static/image.png
這一包沒有重新製作或替換你的貓咪圖片，請把你原本的 image.png 放到 static 資料夾。
若你是覆蓋既有部署，請保留原本 static/image.png。

【資料庫】
仍使用單店獨立 SQLite：pos.db
Zeabur 有 /data 掛載時會優先使用 /data/pos.db。
舊 V1 資料庫啟動時會自動補上 V1.1 新增欄位，不需要手動重建資料庫。

【重要】
正式營業環境更新前，建議先備份 pos.db。
不要拿這包直接覆蓋你自己目前正式營業的原始版本；先在測試部署確認操作流程。

【本次離線檢查】
- Python 語法：通過
- JavaScript 語法：通過
- HTML 解析／重複 ID：通過
- SQLite 流程模擬：通過
  * 銷售單建立 → 編輯 → 作廢 → 庫存回復
  * 進貨 → 作廢 → 復原 → 編輯 → 再作廢
  * 作廢／復原／編輯操作者紀錄
  * 費用支出拆分回傳

注意：此執行環境無法連網安裝 Flask，因此沒有在此環境啟動完整 Flask 瀏覽器實機服務；正式部署後仍應做一輪手機／平板／電腦實機操作測試。
